# Bilingual Interactive Portfolio

Bilingual (English / Kiswahili) interactive portfolio website built with Next.js, PostgreSQL, and Drizzle ORM.

## Features

- Bilingual support (English / Kiswahili)
- Interactive project showcases
- Contact form with database storage
- Admin panel for managing content
- Responsive design

## Quick Start

```bash
npm install
cp .env.example .env
# Configure your database URL in .env
npm run dev
```

## Tech Stack

- Next.js (App Router)
- TypeScript
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
